# ☁️ [CloudDesk] - Help-Desk System

Um sistema de Help-Desk moderno, focado em alta disponibilidade, escalabilidade e boas práticas de engenharia de software. 

Este projeto foi desenvolvido como requisito acadêmico, aplicando na prática conceitos avançados de estruturação de sistemas e serviços distribuídos.

## 📚 Contexto Acadêmico

O projeto integra os conhecimentos de duas disciplinas principais:

*   **Arquitetura de Software:** Aplicação de padrões de projeto (Design Patterns), separação de responsabilidades, modelagem do sistema (ex: Clean Architecture ou Microsserviços) e documentação de decisões arquiteturais (ADRs).
*   **Computação em Nuvem e Web Services:** Desenvolvimento de APIs RESTful/GraphQL, integração contínua, conteinerização e estratégias de deploy (IaaS/PaaS) visando escalabilidade e resiliência na nuvem.

## 🚀 Funcionalidades Principais

*   **Abertura de Chamados (Tickets):** Criação, edição e acompanhamento de chamados pelos usuários.
*   **Gestão de Atendentes:** Fila de atendimento, atribuição de chamados e mudança de status (Aberto, Em Andamento, Concluído).
*   **Notificações:** Alertas via Web Service quando um chamado é atualizado.
*   **Métricas e Relatórios:** Dashboard básico para visualizar o volume de chamados.
